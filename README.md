# EasyBuilder Pro Showcase

Облачная витрина демо-проектов EasyBuilder Pro для демонстрации возможностей HMI-панелей Weintek.

## 📁 Структура проектов

Каждый проект находится в отдельной папке с именем формата `XX-project-name`:

/01-smart-warehouse-AleksandroskoeBOK
/assets
/screenshots ← Оригинальные скриншоты (не коммитятся)
/optimized ← Оптимизированные версии для веба
/raw ← Исходники (не коммитятся)
/source
main_project.emtp ← Исходный файл EBPro (не коммитится!)
metadata.json ← Метаданные проекта
README.md ← Описание проекта


## 🎯 Текущие проекты

### 01-smart-warehouse-AleksandroskoeBOK
**Водоочистной комплекс с. Александровское**

- **Контроллер:** КОНТАР МС12
- **Панель:** MT8102iP
- **Протокол:** Modbus TCP
- **Экранов:** 4
- **Сложность:** Advanced

**Описание:** SCADA-система управления водоочистным комплексом: мониторинг и управление насосными группами, задвижками, контроль уровней в резервуарах.
