# Шаблон проекта-кейса

## Структура
- `assets/optimized/` — оптимизированные изображения (.webp)
- `assets/screenshots/` — исходные скриншоты (.png)
- `assets/raw/` — исходные материалы
- `source/` — исходные файлы EMTP (.emtp, .exob, .CSV)

## Добавление нового кейса
1. Скопируйте эту папку с новым именем: `NN-project-name`
2. Заполните `metadata.json`
3. Добавьте скриншоты в `assets/screenshots/`
4. Добавьте исходники в `source/`
